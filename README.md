# Peminjaman Ruangan Backend

## Deskripsi

Proyek ini adalah bagian backend dari **Sistem Peminjaman Ruangan Kampus**, yang dikembangkan untuk mendigitalisasi proses peminjaman ruangan agar lebih terpusat, terpantau, dan terdokumentasi dengan baik. Backend ini menyediakan API berbasis RESTful untuk mengelola data peminjaman, status, dan riwayat penggunaan ruangan.

## Teknologi

- **Framework**: ASP.NET Core
- **Bahasa**: C#
- **API**: RESTful API

## Cara Menjalankan

### Prerequisites

- .NET SDK (versi sesuai dengan project)
- IDE yang mendukung .NET (Visual Studio, VS Code, atau Rider)

### Langkah-langkah

1. Clone repository ini
2. Navigasi ke folder backend
   ```bash
   cd backend
   ```
3. Restore dependencies
   ```bash
   dotnet restore
   ```
4. Jalankan aplikasi
   ```bash
   dotnet run --project PeminjamanRuangan.Api
   ```
